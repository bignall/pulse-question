# Pulse Question 0.2.0

Ready for Etch and Automatic.css.

- **Automatic.css styling:** the plugin's styles use Automatic.css colours, spacing, type sizes and corners when the site has them, with the logo's orange and teal as fallbacks. Today's question gets a pulse line under it. Your own class styles still win.
- **Turn the styles off** (Questions → Settings → Styles) to style everything in a builder; the markup keeps its `pq-` classes.
- **Builder loops:** use `pq_view` = `today` or `past` in an Etch WP Query loop (or any WP_Query) to show the question of the day or past questions, last asked first.
- **Dates:** a question's date is now the day it was last asked, so loops can show and sort by it.
