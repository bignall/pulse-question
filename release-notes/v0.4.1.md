# Pulse Question 0.4.1

A **Test connection** button for the mailing list, under Questions → Settings → Members. It checks the saved settings one step at a time, says which step failed and what to do, and adds nobody to the list.

For FluentCRM on another site it checks:
- that the site can be reached, and whether a redirect (http → https, or www) drops the login on the way, naming the address to use instead;
- whether the login is accepted, and if not, whether the user name and application password are wrong or right. When they're right, the server is dropping the login header or a security plugin is blocking REST API logins;
- whether that user is allowed to use FluentCRM, and whether FluentCRM is active there;
- whether the list ids in Settings exist, listing the lists that do.

For FluentCRM on this site, it checks that FluentCRM is active and the list ids exist.

A failed sign-up in *Latest subscriptions* now points to the button.
