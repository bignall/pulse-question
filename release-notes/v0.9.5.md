# Pulse Question 0.9.5

Settings stay as you left them.

- **No more autofill on Settings.** Chrome took the Google client ID and secret, and the mailing list user name and application password, for a log-in form. It filled in your own saved email or password, and Save then stored them. These fields, and the Anthropic API key, are now left alone by browsers and password managers until you click into them.
