# Pulse Question 0.1.0

A thought-provoking question every day.

- **Queue** (Questions → Queue): add questions one per line, approve the ones waiting, drag to set the order and see the day each will be asked. "Ask now" changes today's question.
- **Approval:** draft → waiting for approval → approved → asked. Your own questions can be approved straight away. Questions only go public when they're asked.
- **Daily pick** at the time you choose, in the site's timezone. When the queue runs out, the question asked longest ago is asked again.
- **On your site:** "Question of the day" and "Past questions" blocks, `[pulse_question]` and `[pulse_question_past]` shortcodes, a page per question, categories, and `/questions/`. Settings can make a page with both blocks and set it as the home page.
- **To-do Hub:** a task when the queue gets short or questions are waiting for approval.

Requires PHP 8.1+ and WordPress 6.4+.
