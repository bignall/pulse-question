# Pulse Question 0.9.7

The Settings page now runs on WP Foundation.

- **Same page, shared code.** The tabs, the single Save button, the unsaved-changes warnings and the protection against password managers now come from WP Foundation 0.1.5, so other plugins built on it get them too. Everything works as before, and links to a tab, from the setup checklist, To-do Hub or the test buttons, still open the right one.
- **Tidier sign-in settings.** Under **Members**, the Google client ID, client secret and status are on rows of their own. Under **Mailing list**, so are the other site's address, user name and application password.
- **Remove a saved application password.** The mailing list's application password now has a **Remove the saved password** box, like the Anthropic API key and the Google client secret.
