# Pulse Question 0.7.0

Top answers on the home page, so visitors see what others said and want to join in.

- **Top answers under today's question:** the most-liked answers so far, shortened, each with the member's name and likes and a link to the full answer, then a *Read all N answers* link.
- **How many:** three by default. Change it, or set 0 for none, under **Settings → Answers** ("Top answers under today's question").
- **Per page:** the *Question of the day* block can use the setting or its own number, and the shortcode takes `answers`, for example `[pulse_question answers="5"]` or `answers="0"`.
- **Styling:** new `pq-top-answers` and `pq-top-answer` classes, using `--pq-accent`, `--pq-card-bg` and `--pq-radius`.

The daily email picks yesterday's top answers the same way, so the two always agree. Nothing else changes.
